# Documentation

- Every number cites the command or report that produced it.
- Use relative links; keep markdownlint clean (`make lint`).
- ADRs (`docs/adr/NNNN-title.md`) state context, decision, the rejected alternative and consequences.
- Decisions taken without an ADR go in `docs/DECISIONS.md` (date, decision, alternatives, reason).
