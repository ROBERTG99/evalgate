# Add eval cases

Datasets under `evals/datasets/**/*.vN.jsonl` are generated by `data/generator/` (generator 1.0.0, seed 1337, labels by construction) and listed with hashes in `evals/datasets/MANIFEST.json`. Committed files are never edited: a change produces a new version file, and the `pre_tool_guard.py` hook blocks edits to existing ones.

## Steps

1. Decide what changes: toy rows (`evals/datasets/toys/{classify,extract,answer}.vN.jsonl`, FAQ corpus), meta-eval variants (`evals/datasets/meta/variants.vN.jsonl`) or judge labels (`evals/datasets/judge/answer_correctness.labels.vN.jsonl`). Keep the row contract: `{"id", "split": "dev|test", "input", "expected", "tags", "meta"}`.
2. Write the failing test in `tests/unit/generator/` (for example the new row count and the dev/test split, or a property of the new rows), and keep `tests/unit/generator/test_reproducible.py::test_manifest_hashes_match` in mind.
3. Change the generator in `data/generator/`, not the JSONL. Add new rows after the existing ones, write to the next version (`classify.v2.jsonl`), keep the seed at 1337 and derive labels by construction. New ids never reuse old ones.
4. Regenerate and check:

   ```bash
   make seed-data
   ```

   It runs `python -m data.generator --check`, writes the new version and verifies `MANIFEST.json`. Run it twice: the output must be byte-identical.
5. Point the suite in `evals/suites/` at the new version only when you mean to; never move rows between `dev` and `test`, and never pick rows by looking at `test` results.
6. Run `uv run pytest tests/unit/generator -q` and `make eval`, then let the `eval-analyst` subagent confirm thresholds still hold.
7. Record the change, row counts and the reason in `docs/DECISIONS.md` and evidence in `PROGRESS.md`. If labels changed, add the maintainer review to "Needs the maintainer" in `PROGRESS.md`.

## Done when

- The new `.vN.jsonl` file exists beside the old one, which is byte-for-byte unchanged.
- `make seed-data` passes twice with identical hashes in `evals/datasets/MANIFEST.json`.
- No suite threshold was lowered and no `test` row was chosen by looking at results.
