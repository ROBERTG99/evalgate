# Architecture Decision Records

Each ADR records one architectural choice: its context, the decision, the alternatives that were rejected and why, and the positive and negative consequences. Numbers in an ADR cite the code or the report in `evals/reports/` that produced them. Smaller decisions without an ADR are listed in [docs/DECISIONS.md](../DECISIONS.md). An ADR is never deleted; a replaced one gets the status `Superseded by ADR-NNNN`.

To add an ADR, follow the `new-adr` skill in `.claude/skills/new-adr/SKILL.md`: take the next number, name the rejected alternative, cite every number, and lint with `.tools/bin/markdownlint-cli2 "docs/adr/*.md"`.
